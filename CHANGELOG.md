# Changelog

## 1.1.0
- Self-contained notebook (generated by `scripts/build_standalone_notebook.py`); no repository clone needed.
- LLM provider auto-detected from available API key; tolerant of a model name in `LLM_PROVIDER`; `GEMINI_MODEL`/`GROQ_MODEL`
  read from Colab secrets; `list_gemini_models()` helper (supports Gemma on AI Studio).
- Live-crew failures fall back to offline mode with a clear message.
- Added missing `litellm` and `google-genai` requirements (needed by CrewAI for Groq / Gemini).

## 1.0.0
- Initial release: synthetic telemetry, hybrid detection, ChromaDB RAG knowledge base, four-agent CrewAI crew,
  offline mode, evaluation, notebook, tests and documentation.
